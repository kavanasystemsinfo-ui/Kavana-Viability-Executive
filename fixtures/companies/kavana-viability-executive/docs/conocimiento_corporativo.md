# Base de Conocimiento Corporativo - Kavana Apartaments

## 1. Marco Normativo Clave (España / Comunitat Valenciana)

### Ley de Ordenación de la Edificación (LOE - Ley 38/1999)
- **Garantías**: 1 año (acabados), 3 años (habitabilidad), 10 años (estructura)
- **Responsabilidades**: Promotor, constructor, proyectista, director de obra, entidades de control
- **Seguro decenal**: Obligatorio para viviendas nuevas (cobertura daños estructurales 10 años)

### Código Técnico de la Edificación (CTE)
- **DB-HE** (Ahorro de energía): Exigencia certificación energética, limitación demanda, energías renovables
- **DB-SI** (Seguridad incendie): Sectorización, evacuación, instalaciones protección
- **DB-SUA** (Seguridad utilización): Accesibilidad, prevención caídas, ventilación
- **DB-HR** (Protección frente ruido): Aislamiento acústico particiones, fachadas

### Legislación Urbanística Valenciana (LOTUP, LUV)
- **Planeamiento**: PGOU, Planes Parciales, Estudios de Detalle
- **Licencias**: Obra mayor (proyecto básico + ejecución), Primera Ocupación
- **Cesiones**: 10% suelo dotacional / 5% vivienda protegida (según municipio)
- **Plazos máximos**: Licencia 3-6 meses (silencio administrativo = desestimatorio en CV)

### Fiscalidad Inmobiliaria
- **IVA**: 10% vivienda nueva (entrega + primera transmisión), 21% locales/garajes no vinculados
- **ITP**: 10% (CV) transmisiones posteriores (exento IVA)
- **Plusvalía municipal (IIVTNU)**: Incremento valor suelo, sujeto a plusvalía real
- **Sociedades**: 25% tipo general, deducciones R&D, amortización libertad

## 2. Métricas y Ratios Sectoriales (Promoción Residencial)

### Viabilidad Económica
- **Margen bruto objetivo**: 18-22% sobre ingresos
- **Margen neto objetivo**: 12-16% sobre ingresos
- **LTV máximo bancario**: 60-65% sobre tasación (no coste)
- **Pre-ventas mínimas financiación**: 30% (senior), 15-20% (mezzanine)
- **DSCR objetivo**: >1,2x (senior), >1,1x (blendado)
- **Coste medio deuda**: Euribor + 1,75-2,25% (senior), 7-9% (mezzanine)

### Operativos
- **Plazo medio licencia**: 6-12 meses (CV), 12-18 meses (Madrid/Barcelona)
- **Plazo construcción**: 18-24 meses (bloque 60-100 uds)
- **Velocidad venta objetivo**: 1,0-1,5 uds/mes/promo (lanzamiento), 0,5-0,8 (remate)
- **CAC (Coste Adquisición Cliente)**: 4.000-8.000€/ud (digital + portales + comercial)
- **Absorción mercado**: 6-12 meses stock medio zona prime

### Tesorería
- **Curva de caja típica**: -30% inicio, -60% mes 12, -90% mes 18, +100% entrega
- **Runway mínimo**: 18 meses caja libre
- **Concentración bancaria**: Máx 40% deuda con una entidad

## 3. Procesos Críticos Kavana Apartaments

### Ciclo de Vida Promoción
```
1. ORIGINACIÓN SUELO (2-6 meses)
   → Identificación → Due Diligence (legal, técnico, comercial, financiero)
   → Opción compra (3-6% precio, 6-12 meses) → Ejercicio opción → Escrituras

2. PLANEAMIENTO Y LICENCIA (6-18 meses)
   → Proyecto Básico → Solicitud Licencia → Alegaciones/Subsanaciones → Licencia

3. FINANCIACIÓN Y CONTRATACIÓN (2-4 meses)
   → Tasación → Negociación préstamo promotor → Firma escritura préstamo
   → Concurso constructora → Adjudicación → Contrato llave en mano

4. EJECUCIÓN OBRA (18-24 meses)
   → Replanteo → Estructura → Cerramiento → Instalaciones → Acabados → Urbanización
   → Controles calidad (quincenales) → Certificaciones mensuales → Modificaciones

5. ENTREGA Y POSTVENTA (3-6 meses)
   → Recepción provisional → LPO → Entregas notariales → Subrogaciones hipotecarias
   → Postventa 2 años (LOE) → Garantía decenal 10 años
```

### Comité de Promociones (Quincenal)
- **Asistentes**: CEO, CFO, COO, CLO, CPO, Jefes Proyecto (según agenda)
- **Orden del día**: Hitos críticos, desviaciones >5% plazo/coste, riesgos, decisiones
- **Output**: Acta con decisiones, responsables, plazos

### Comité de Riesgos Financiero (Mensual)
- **Asistentes**: CEO, CFO, Tesorería
- **Temas**: Posición caja 13 semanas, desviaciones presupuesto, covenants, nuevas necesidades

### Junta Directiva (Trimestral)
- **Asistentes**: Socios, CEO, CFO, COO, CLO, CMO, CPO
- **Temas**: Cuentas trimestrales, pipeline, decisiones estratégicas (>5M€), gobernanza

## 4. Terminología Especializada (Glosario)

| Término | Definición |
|---------|------------|
| **Promotor** | Empresa que impulsa, financia y comercializa la promoción; asume riesgo |
| **Constructor** | Ejecuta obra bajo contrato (llave en mano, gestión, precio cerrado) |
| **Project Finance** | Financiación no-recourse sobre flujos de la promoción (no balance corporativo) |
| **LTV (Loan-to-Value)** | Préstamo / Valor tasación. Banco mira tasación, no coste |
| **DSCR (Debt Service Coverage Ratio)** | NOI / Servicio deuda. Mide capacidad pago |
| **Pre-ventas / Reservas** | Contratos de arras (10% precio) firmados antes de entrega |
| **Remanente** | Unidades sin vender próximas a entrega / entregadas |
| **Absorción** | Unidades vendidas / mes / promoción |
| **Stock** | Unidades disponibles para la venta |
| **CAC** | Coste total marketing+comercial / nº ventas cerradas |
| **NAV (Net Asset Value)** | Valor activos - deuda neta. Métrica valor accionista |
| **Suelo finalista** | Suelo con planeamiento aprobado, listo para licencia |
| **Suelo en cartera** | Suelo en fase planeamiento (opción, due diligence) |
| **Plusvalía** | Incremento valor suelo por actuación urbanística |
| **Cesiones** | Suelo/edificabilidad cedida a ayuntamiento (dotaciones, VPO) |
| **LPO (Licencia Primera Ocupación)** | Permite habitar y entregar viviendas; requisito para escrituras |
| **Subrogación hipotecaria** | Comprador asume préstamo promotor; libera deuda promotor |

## 6. Políticas y Procedimientos Internos

### Política de Calidades (Memoria Base)
- **Estructura**: Hormigón HA-30/HA-40, armado B500S
- **Fachada**: SATE (aislamiento exterior) + cerámico / piedra natural
- **Carpintería exterior**: PVC rotura puente térmico, vidrio bajo emisivo (U<1,3)
- **Climatización**: Aerotermia (ACS + climatización) + suelo radiante refrescante
- **Agua caliente**: Aerotermia + apoyo solar térmico (obligatorio CTE)
- **Fotovoltaica**: Autoconsumo 3-5 kW/vivienda (política certificacion A/B)
- **Aislamiento acústico**: DnT,w > 53 dB particiones, > 45 dB fachada
- **Domótica**: Preinstalación estándar (iluminación, clima, persianas)

### Política Comercial
- **Fases lanzamiento**: 1) VIP/Lista espera (2 sem), 2) Público general
- **Reserva**: 3.000€ (descontable firma), validez 30 días
- **Contrato arras**: 10% precio (incluye reserva), plazo 60-90 días a notaría
- **Personalización**: Packs cerrados (cocina, baños, suelos, domótica) hasta hito "cerramiento"
- **Extras**: Valoración individual, aprobación CPO + CFO si >5k€/ud

### Política de Tesorería
- **Caja mínima**: 3M€ libres en todo momento
- **Previsión**: Rolling 13 semanas, actualización viernes
- **Pagos proveedores**: 60 días estándar, 30 días constructoras (certificación mensual)
- **Concentración**: Máx 25% caja en una entidad
- **Inversión temporal**: Cuentas remuneradas / fondos monetarios (sin riesgo)
